# Kontrol FREKUENSI 03:17

| Tombol | Fungsi |
|---|---|
| W / A / S / D | Bergerak |
| Mouse | Melihat ke segala arah |
| Shift | Berlari |
| Ctrl | Merunduk |
| F | Interaksi / masuk atau keluar tempat sembunyi |
| T | Menyalakan atau mematikan senter |
| J | Membuka jurnal |
| Q / E | Mengubah frekuensi radio |
| Slider radio | Pengaturan frekuensi secara presisi |
| 0–9 / numpad | Memasukkan kode panel |
| Enter | Konfirmasi panel |
| Backspace | Hapus digit kode |
| Esc | Jeda / tutup panel |

Klik area game untuk mengaktifkan mouse lock. Saat panel atau menu terbuka, mouse dilepas supaya tombol UI bisa digunakan.
